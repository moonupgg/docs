---
title: "MoonUP 販売者API"
description: "独自のツールから出品を公開・管理できます。"
---

販売者のインテグレーションが出品カタログを最新に保つために必要なものがすべて揃っています。出品の作成、在庫の補充、非公開化、アーカイブ。

カテゴリごとに独自のパス（`/v1/offers/accounts`、`/v1/offers/currency` など）と独自のフィールドがあります。販売しているカテゴリとだけ連携すればよく、後からプラットフォームに追加されたカテゴリがあなたの連携に影響することはありません。

これは公開インターフェースです。販売者ダッシュボード固有の画面（出金、紛争、アカウント設定）は含まれず、APIキーからはアクセスできません。

*出品*はマーケットプレイス上の1つの掲載を指します。APIではこれを `offers` と呼び、以下でも同様です。

## ベースURL

```
https://api.moonup.gg
```

HTTPSのみで、すべてのパスはバージョン付きです：`/v1/...`。

## 最初のリクエスト

<Steps>
  <Step title="キーを作成する">
    販売者ダッシュボードの **販売者 → APIキー** でキーを作成します。キーは一度しか表示されません。その場でコピーしてください。後から読み出す方法はありません。
  </Step>
  <Step title="キーを送信する">
    キーはすべてのリクエストの `Authorization` ヘッダーに含めます。何かと交換する必要はありません。

    ```bash
    curl -H "Authorization: Bearer $MOONUP_API_KEY" \
      https://api.moonup.gg/v1/offers/accounts/my
    ```
  </Step>
  <Step title="カテゴリ固有のフィールドを確認する">
    カテゴリの作成APIが受け付ける内容は、そのカテゴリ自身のリファレンスページに記載されています。アカウントの出品には価格と画像、通貨の出品には商品と在庫があります。ゲームによって変わるのは `attributes` で、スキーマエンドポイントがフィールド、型、必須項目を返します。

    ```bash
    curl https://api.moonup.gg/v1/offers/games/roblox/categories/accounts/schema
    ```

    このパスはゲームの `slug` を受け付けます。その他のカタログパスでは `GET /v1/offers/games` が返す `id` でゲームを指定します。そこでslugを使うと `400` が返ります。

    カタログの読み取りは公開されているので、キーを取得する前でも試せます。
  </Step>
</Steps>

## ステータス

新しい出品は `draft` です。あなただけのもので、他の人には見えません。`publish` で `active` になり、その瞬間から購入者が購入できます。事前の審査はありません。販売できる在庫がない出品を公開しようとすると `409` で拒否されるので、先に在庫を追加してください。編集しても出品のステータスは変わりません。`active` の出品は公開されたまま、`draft` は下書きのままです。

`unpublish` は `active` の出品を `draft` に戻します。`archived` は最終状態です。`DELETE` は出品を完全に取り下げますが、あなたは引き続き閲覧できます。`sold` はAPI呼び出しではなく注文によって決まり、最後のユニットが完了した注文に渡った状態です。在庫がすべて進行中の注文に入っている出品は `active` のままで、注文がキャンセルされると在庫が戻ります。

モデレーションは公開中の出品を `changes_requested` として差し戻すことがあります。出品はマーケットプレイスから外れ、`moderation_reason_code` と `moderation_note` で修正箇所が示されます。次の `PATCH` で `draft` になるので、修正後に `publish` してください。明らかな規約違反でモデレーションが削除した出品は消去され、それに対するすべての呼び出しは `404` を返します。

## 価格

このAPIの価格はすべて米セント単位の整数です。`price: 4990` は49.90ドルです。小数の金額はなく、通貨は `USD` のみです。
