## Leveranstid

Leveranstiden beror på valt spel, produkttyp och säljarens tillgänglighet.

Typiska leveranstider visas på varje produktsida innan du beställer.

**Beräknad leverans**

- Direktleverans — inom några minuter
- Snabb leverans — upp till 30 minuter
- Standardleverans — 1–24 timmar
- Schemalagd leverans — vid en överenskommen tid

Om din beställning tar längre tid än väntat kan du följa den under Köp eller kontakta vårt supportteam.

## Handelsmetoder

Olika spel kräver olika leveransmetoder.

Vanliga handelsmetoder:

- Direkthandel i spelet
- Auktionshus
- Annonser på marknadsplatsen
- Leverans via post
- Handelsförfrågan
- Gåvosystem

Den handelsmetod som krävs anges alltid på produktsidan före köpet.

Om ytterligare steg behövs kontaktar säljaren dig via orderchatten.

## Regionbegränsningar

Viss spelvaluta kan bara levereras inom vissa spelregioner eller servrar.

Innan du beställer, kontrollera:

- Spelregion
- Server
- Plattform
- Att karaktären är tillgänglig

Köp av valuta för fel region kan fördröja leveransen eller kräva att beställningen avbryts.

Dubbelkolla alltid vald server innan du slutför betalningen.

## Säkerhet

Din säkerhet är vår högsta prioritet.

MoonUP samarbetar bara med verifierade säljare och erbjuder köparskydd för berättigade köp.

**Tips för säker handel**

- Dela aldrig ditt lösenord.
- Följ säljarens leveransinstruktioner.
- Kontrollera dina server- och karaktärsuppgifter noga.
- Sköt all kommunikation via orderchatten.
- Kontakta support direkt om du märker något ovanligt.

Vårt team övervakar kontinuerligt transaktioner för att säkerställa en trygg marknadsplats för alla kunder.

## Misslyckad leverans

En leverans kan ibland misslyckas på grund av spelbegränsningar, felaktig information eller tillfälliga serverproblem.

Vanliga orsaker:

- Fel server vald
- Karaktären är inte tillgänglig
- Handelsbegränsningar
- Underhåll av spelet
- Säljaren kan inte slutföra leveransen

Om leveransen inte kan slutföras granskar vårt team beställningen och hjälper till att lösa problemet så snabbt som möjligt.

Beroende på situationen kan du få:

- Ett nytt leveransförsök
- Ett uppdaterat leveransschema
- En ersättningslösning
- Full eller delvis återbetalning, när det är tillämpligt
