## 전달 시간

전달 시간은 선택한 게임, 상품 유형, 판매자 상황에 따라 다릅니다.

일반적인 예상 전달 시간은 주문 전에 모든 상품 페이지에 표시됩니다.

**예상 전달**

- 즉시 전달 — 몇 분 이내
- 빠른 전달 — 최대 30분
- 일반 전달 — 1~24시간
- 예약 전달 — 합의된 시간

주문이 예상보다 오래 걸리면 구매 내역에서 진행 상황을 확인하거나 고객지원팀에 문의하세요.

## 거래 방식

게임마다 전달 방식이 다릅니다.

일반적인 거래 방식:

- 게임 내 직접 거래
- 경매장
- 거래소 등록
- 우편 전달
- 거래 요청
- 선물 시스템

필요한 거래 방식은 구매 전에 항상 상품 페이지에 표시됩니다.

추가 단계가 필요하면 판매자가 주문 채팅으로 연락합니다.

## 지역 제한

일부 게임 머니는 특정 게임 지역이나 서버에서만 전달할 수 있습니다.

주문 전에 다음을 확인하세요:

- 게임 지역
- 서버
- 플랫폼
- 캐릭터 사용 가능 여부

잘못된 지역의 게임 머니를 구매하면 전달이 지연되거나 주문을 취소해야 할 수 있습니다.

결제 전에 선택한 서버를 항상 다시 확인하세요.

**지역을 다시 확인하세요**

</Warning>

## 안전

회원님의 안전이 최우선입니다.

MoonUP은 인증된 판매자와만 거래하며, 해당하는 구매에 구매자 보호를 제공합니다.

**안전한 거래 팁**

- 비밀번호를 절대 공유하지 마세요.
- 판매자의 전달 안내를 따르세요.
- 서버와 캐릭터 정보를 꼼꼼히 확인하세요.
- 모든 대화는 주문 채팅에서 하세요.
- 이상한 점이 보이면 즉시 고객지원에 문의하세요.

팀은 모든 고객에게 안전한 마켓플레이스를 제공하기 위해 거래를 지속적으로 모니터링합니다.

## 전달 실패

게임 제한, 잘못된 정보, 일시적인 서버 문제로 전달이 실패할 수 있습니다.

일반적인 원인:

- 잘못된 서버 선택
- 캐릭터를 사용할 수 없음
- 거래 제한
- 게임 점검
- 판매자가 전달을 완료할 수 없음

전달을 완료할 수 없으면 팀이 주문을 검토하고 최대한 빨리 문제 해결을 도와드립니다.

상황에 따라 다음을 받을 수 있습니다:

- 새로운 전달 시도
- 변경된 전달 일정
- 대체 해결책
- 해당하는 경우 전액 또는 부분 환불
